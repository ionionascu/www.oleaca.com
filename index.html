I’ve been writing production software for 20 years, in environments where downtime is measured in lost revenue and headlines.

I work as an independent contractor through ION++ Ltd, a UK-registered company. My focus is the messy middle — the architecture and lead-developer work where someone has to own end-to-end delivery of a system that’s real, regulated and in production at scale: designing the system, then writing a meaningful share of the code in Java, Rust, TypeScript or Swift as the problem demands.

I’m currently Principal Software Engineer at Klarna, engaged through ION++. I’ve been the architect behind Sky’s Identity Portal (~30M user profiles), the technical lead on Vodafone’s offers platform across 7+ operating companies, and the cloud engineer on cross-cloud proofs-of-concept for the UK Home Office. Spring since 1.2; Java since 1.4; AWS for over twelve years; Rust and AI engineering as the current frontier.

Claude Code is my daily environment for design and implementation. I write my own skills, agents and hooks so the tooling carries my conventions and review standards into every codebase I touch — an engineering discipline with guardrails, not autocomplete.

I’m equally comfortable producing a roadmap that earns board confidence and shipping the Java, Rust and Terraform that delivers it — from a fixed-fee architecture review to a long-running lead-developer engagement.
